Binary Search was successfully implemented and tested. It searches for the required element by repeatedly dividing the sorted list into two halves and comparing the middle element with the target value. From this practical, it is concluded that Binary Search is an efficient searching algorithm for sorted datasets and performs much faster than Linear Search for large datasets.
Time Complexity:
Best Case: O(1)
Average Case: O(log n)
Worst Case: O(log n)
Space Complexity: O(1)
