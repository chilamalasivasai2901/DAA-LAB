Quick Sort was successfully implemented and tested. It uses the divide-and-conquer technique to sort elements by selecting a pivot and partitioning the array into smaller subarrays. The algorithm is efficient, easy to implement, and performs well for sorting large datasets. From this practical, it is concluded that Quick Sort is a fast and widely used sorting algorithm in many real-world applications.
Time Complexity:
Best Case: O(n log n)
Average Case: O(n log n)
Worst Case: O(n²)
Space Complexity: O(log n) (recursive stack; this implementation also creates new lists)
