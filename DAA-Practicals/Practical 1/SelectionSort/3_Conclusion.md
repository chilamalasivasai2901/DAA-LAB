Selection Sort was successfully implemented and tested. It sorts the elements by repeatedly finding the smallest element from the unsorted part of the array and placing it in its correct position. The algorithm is simple and easy to understand, making it suitable for learning basic sorting concepts. From this practical, it is concluded that Selection Sort is useful for small datasets and helps in understanding the fundamentals of sorting techniques.
Time Complexity:
Best Case: O(n²)
Average Case: O(n²)
Worst Case: O(n²)
Space Complexity: O(1)
